# Event tag notices

`event-notice-<language>.taf` is what a box without the custom firmware
plays when an event tag is placed on it (setting
`cfw.event_notice_language`). Made with the Piper text-to-speech
engine (https://github.com/rhasspy/piper) and encoded with
`teddycloud --encode`:

| File | Voice | Voice data licence |
| --- | --- | --- |
| `event-notice-de.taf` | de_DE-thorsten-high, Thorsten Müller (Thorsten-Voice) | CC0 |
| `event-notice-en.taf` | en_GB-cori-high (LibriVox recordings) | public domain |
| `event-notice-fr.taf` | fr_FR-siwis-medium, SIWIS French Speech Synthesis Database (University of Edinburgh) | CC BY 4.0 |

Texts:

- de: "Ich bin ein Event-Tonie, aber leider hat deine Box keine Custom-Firmware installiert."
- en: "I am an event Tonie, but unfortunately your box does not have custom firmware installed."
- fr: "Je suis un Tonie événement, mais malheureusement ta box n'a pas de firmware personnalisé installé."
